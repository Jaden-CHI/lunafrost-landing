> **TL;DR** — [anomalyco/hex](https://github.com/anomalyco/hex)는 Rust로 만든 오픈소스 로컬 음성 받아쓰기 도구다. Option 키를 누른 채 말하고 손을 떼면 현재 포커스된 앱에 전사 텍스트가 붙여넣어진다. 온디바이스 처리라 오디오가 외부 서버로 나가지 않고, TypeScript 설정 파일로 커스텀 변환까지 정의할 수 있다.

---

## 왜 "또 다른 음성 도구"가 아닌가

클라우드 기반 음성 API는 강력하지만, 개발자와 크리에이터에게 걸리는 지점이 있다. 오디오가 외부 서버로 전송된다는 사실이다. 미팅 내용, 코드 리뷰 코멘트, 개인 메모 등 민감한 맥락에서 쓰기가 꺼려진다.

[anomalyco/hex](https://github.com/anomalyco/hex)는 이 문제를 정면 돌파한다. 전사 모델이 디바이스에서 직접 실행되고, **일반 받아쓰기에는 클라우드 서비스가 전혀 필요하지 않다**. README는 "ordinary dictation does not require OpenCode or a cloud transcription service"라고 명시한다.

2026-11-02 01:28 UTC 기준 GitHub 스타 1,179개로 트렌딩에 신규 진입했다(agents-radar 자동 수집 관측).

## 핵심 동작 방식

Hex의 UX는 단순하다.

| 시나리오 | 동작 |
|---|---|
| 기본 받아쓰기 | Option 누른 채 말하고 놓기 → 현재 앱에 붙여넣기 |
| 연속 녹음 | Option 더블탭 → 다시 Option 눌러 종료 |
| 마지막 받아쓰기 재붙여넣기 | Option-Shift-V |
| 커스텀 변환 | `~/.config/hex/hex.config.ts` 작성 (TypeScript/JS) |
| 에이전트 스킬 등록 | `npx skills add anomalyco/hex --skill hex-personal-commands` |

특정 앱을 열 필요도, 텍스트 필드를 클릭할 필요도 없다. 포커스가 있는 곳이면 어디서나 동작한다. 터미널에서 명령어를 불러도 되고, 에디터 주석을 말해도 된다.

---

## 스트리밍 전사와 메모리 개선

Hex 2.3.0부터 macOS, Linux, Windows 전 플랫폼에서 **스트리밍 전사**가 도입됐다. 말하는 동안 전사가 동시에 진행되므로, 단축키를 놓는 순간 약 0.1초 만에 결과가 나온다. 긴 문장을 말한 뒤 처리를 기다리던 경험이 사라진다.

Hex 3.0.0에서는 로컬 모델의 메모리 사용량이 약 900MB에서 약 160MB로 줄었다. 여러 무거운 앱을 띄워두는 개발자 환경에서 의미 있는 변화다.

최신 3.1.2에서는 조용한 내장 마이크 환경에서 처음 2.5초만 녹음되고 잘리던 버그가 수정됐다.

## 프라이버시 설계

[README](https://github.com/anomalyco/hex/blob/dev/README.md)에 명시된 데이터 처리 방침은 다음과 같다.

- **오디오 저장 안 함**: 기본적으로 받아쓰기 오디오를 저장하지 않는다.
- **히스토리 보관**: 성공적으로 붙여넣어진 텍스트를 기본 7일간 로컬 보관한다. 로컬 전사본, 최종 텍스트, 제한된 앱 및 타이밍 메타데이터를 포함한다.
- **저장하지 않는 것**: 오디오 파일, 전체 브라우저 URL, 창 제목.

민감한 내용을 말해도 오디오 자체가 디바이스 밖을 나가지 않는다는 설계다.

## 개발자를 위한 확장 포인트

### TypeScript 커스텀 변환

고급 사용자는 `~/.config/hex/hex.config.ts`를 생성해 받아쓰기 변환 규칙을 직접 정의할 수 있다. 예를 들어 "깃헙 이슈 번호"를 말하면 `#1234` 형식으로 자동 변환하거나, 특정 약어를 전체 단어로 풀어쓰는 규칙을 추가할 수 있다.

### TypeScript SDK 통합

자체 애플리케이션에 로컬 전사 기능을 내장하려면 `@kitlangton/hex` 패키지를 사용한다. Promise API와 선택적 Effect API를 모두 제공해 기존 비동기 코드에 자연스럽게 녹여 쓸 수 있다.

### 코딩 에이전트 스킬

커스텀 커맨드 설정을 코딩 에이전트에게 가르치려면 공식 스킬을 추가하면 된다.

```bash
npx skills add anomalyco/hex --skill hex-personal-commands
```

에이전트가 Hex 설정 방식을 이해하고 개인화된 변환 규칙 작성을 도와준다.

## 설치

현재 공식 지원 플랫폼은 **macOS 15 이상 Apple Silicon**이다. Windows와 Linux는 베타로 다운로드를 지원하지만, 전체 기능 범위는 공식 문서 기준으로 아직 베타 단계다.

**Homebrew (macOS)**

```bash
brew install --cask anomalyco/tap/hex
```

**Nix**

```bash
nix profile install github:anomalyco/hex
```

---

## 한계와 확인 안 된 사항

글을 쓰는 시점에서 확인되지 않은 사항도 있다. 저장소 `LICENSE` 파일에서 라이선스 종류를 직접 확인하지 못했다. Windows 정식 지원 시기는 공개 자료에서 나오지 않는다. Linux의 X11/Wayland 전체 기능 지원 범위도 README는 "Linux Beta"로만 표기한다. 스타 수는 2026-11-02 단일 시점 스냅숏이므로 추세를 주장하는 근거로 쓸 수 없다.

## 정리

클라우드 음성 API가 기본값이 된 환경에서 Hex는 반대 방향을 택했다. 온디바이스 처리, 단축키 하나, 어느 앱에나 붙여넣기. 터미널, 에디터, 메모 앱, 슬랙까지 포커스가 있는 곳이면 어디든 동작한다. TypeScript 설정과 SDK로 개발자 확장성도 열려 있다. macOS Apple Silicon 사용자라면 [`brew install --cask anomalyco/tap/hex`](https://github.com/anomalyco/hex) 한 줄로 바로 시작할 수 있다.
