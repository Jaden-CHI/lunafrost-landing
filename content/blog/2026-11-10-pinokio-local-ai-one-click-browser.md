> 2026-11-10 누락분을 2026-11-14에 보완 발행한 글입니다.

**TL;DR** — Pinokio는 `git clone`, `conda`, `pip`, CUDA 환경 설정 없이 AI 앱을 원클릭으로 로컬 설치·실행하는 "AI 브라우저"입니다. MIT 라이선스·무료이며, ComfyUI·Ollama·AudioCraft·Wan2.1 등 200개 이상의 오픈소스 앱을 지원합니다. 단, 런타임 바이너리 자체는 오픈소스가 아님을 인지하고 사용해야 합니다.

---

## Pinokio가 해결하는 문제

로컬 AI 도구를 직접 설치하면 으레 이런 경험을 하게 됩니다.

```
# 대충 이런 과정이 반복된다
git clone https://github.com/some/ai-project
conda create -n myenv python=3.10
conda activate myenv
pip install -r requirements.txt
# CUDA 버전 불일치 → 에러 → 검색 → 재시도 ...
```

Python 버전 충돌, CUDA 미스매치, 의존성 지옥. 이 단계에서 포기하는 개발자와 크리에이터가 적지 않습니다. Pinokio는 이 과정 전체를 추상화합니다.

[공식 GitHub 조직(`github.com/pinokiocomputer`)](https://github.com/pinokiocomputer)에 따르면, Pinokio는 스스로를 **"AI Browser"**로 소개합니다. AI 애플리케이션과 모델을 자동으로 설치·실행·자동화할 수 있는 로컬 브라우저이며, 사용자가 터미널을 직접 다룰 필요가 없습니다.

---

## 핵심 구조

[공식 문서(`github.com/pinokiocomputer/docs.pinokio.computer`)](https://github.com/pinokiocomputer/docs.pinokio.computer/blob/main/index.md) 기준으로 Pinokio의 작동 방식은 다음과 같습니다.

- **단순 JSON 스크립트 기반 자동화**: 파일 작성·다운로드·라이브러리 설치·앱 실행 등 컴퓨터의 모든 작업을 JSON으로 기술하고 Pinokio가 대신 처리합니다.
- **중앙화된 홈 디렉터리**: 모든 앱과 파일은 단일 Pinokio Home Directory 안에 격리 저장됩니다. 각 앱의 환경이 서로 간섭하지 않습니다.
- **내장 브라우저 뷰**: Install 버튼을 누르면 Pinokio가 GitHub 저장소를 pull하고, Python·CUDA 환경을 자동 구성한 뒤, 내장 브라우저 창에서 바로 앱을 열어줍니다.

### 지원 플랫폼

macOS, Windows, Linux를 모두 지원합니다.

---

## 설치부터 앱 실행까지 — 공식 문서 기반 흐름

아래는 [공식 문서](https://github.com/pinokiocomputer/docs.pinokio.computer/blob/main/index.md)와 [공식 GitHub](https://github.com/pinokiocomputer)을 근거로 정리한 흐름입니다. 필자가 직접 실행하여 재현을 검증한 것이 아님을 미리 밝힙니다.

### 1단계 — Pinokio 설치
공식 사이트 또는 GitHub Releases 페이지에서 플랫폼별 바이너리를 다운로드합니다. 제3자 소프트웨어 사이트 MajorGeeks에는 2026-11-05 기준 버전 8.3.7이 등록되어 있으나([관측일: 2026-11-14](https://www.majorgeeks.com/files/details/pinokio.html)), 공식 GitHub Releases 페이지에서 버전을 직접 확인하는 것을 권장합니다.

### 2단계 — Discover 페이지 탐색
Pinokio를 실행하면 Discover 페이지에서 카탈로그를 탐색할 수 있습니다. 현재 카탈로그에는 200개 이상의 커뮤니티 유지 앱 스크립트가 포함되어 있습니다.

| 카테고리 | 대표 앱 |
|----------|---------|
| 이미지 생성 | ComfyUI, Automatic1111 |
| LLM 로컬 실행 | Ollama, Text Generation WebUI |
| 영상 생성 | Wan2.1 |
| 음악 생성 | AudioCraft |
| 음성 클로닝 | (카탈로그 내 복수 도구) |

### 3단계 — 원클릭 설치
원하는 앱의 **Install** 버튼을 클릭합니다. Pinokio가 내부적으로 다음 작업을 처리합니다.

```
# Pinokio가 대신 처리하는 과정 (사용자는 클릭만)
1. GitHub 저장소 pull
2. 샌드박스 Python 환경 구성
3. 의존성 설치
4. 앱 기동 → 내장 브라우저 뷰에서 열기
```

### 4단계 — 자동화 파이프라인 구성 (선택)
JSON 스크립트를 작성하면 여러 앱의 설치·실행·결과 연결을 자동화할 수 있습니다. 예를 들어 텍스트 생성 → 이미지 생성 → 음성 합성을 하나의 파이프라인으로 묶는 방식이 가능합니다.

## 라이선스와 오픈소스 범위

Pinokio 애플리케이션 자체는 **MIT 라이선스, 무료**입니다([공식 GitHub](https://github.com/pinokiocomputer) 기준, 가격 마지막 검증: 2026-03-22). 유료 플랜이나 크레딧 없이 모든 기능을 사용할 수 있습니다.

단, 중요한 주의사항이 있습니다. **런타임 바이너리는 오픈소스가 아닙니다.** 커뮤니티에서 지적되는 사항으로, 공식 측의 별도 공식 설명은 현재 확인되지 않습니다. Pinokio가 설치·실행하는 개별 앱들(ComfyUI, Ollama 등)은 모두 각자의 오픈소스 라이선스를 따릅니다.

> ⚠️ 일부 제3자 리뷰 사이트에서 "freemium/paid" 표기가 혼재합니다. 가격 정책은 공식 사이트(`pinokio.computer`)에서 직접 확인하세요.

## 개발자·크리에이터 관점에서의 포지셔닝

Pinokio는 특정 AI 모델이나 앱이 아니라, **로컬 AI 도구 전체를 위한 런처 플랫폼**입니다.

- **개발자라면**: 각 AI 프로젝트의 환경을 직접 관리하는 대신, Pinokio 홈 디렉터리 하나로 격리된 환경을 일괄 관리할 수 있습니다. JSON 스크립트 자동화는 CI 파이프라인처럼 로컬 AI 워크플로를 구성하는 데 활용됩니다.
- **크리에이터라면**: ComfyUI로 이미지를 생성하고, Wan2.1로 영상을 만들고, AudioCraft로 배경음악을 생성하는 작업 흐름을 터미널 없이 구성할 수 있습니다. 클라우드 API 비용 없이 GPU를 직접 사용하는 로컬 파이프라인의 진입 장벽을 낮추는 것이 Pinokio의 핵심 가치입니다.

## 정리

Pinokio는 "로컬 AI를 써보고 싶지만 환경 설정이 두렵다"는 개발자와 크리에이터 모두를 위한 도구입니다. MIT 라이선스·무료라는 조건, 200개 이상의 카탈로그, macOS·Windows·Linux 지원이라는 사실은 [공식 GitHub](https://github.com/pinokiocomputer)과 [공식 문서](https://github.com/pinokiocomputer/docs.pinokio.computer/blob/main/index.md)로 검증됩니다. 런타임 바이너리의 비공개 범위는 커뮤니티에서 지속적으로 논의 중인 사항이므로, 프로덕션 환경 도입 전에는 이 점을 고려하세요.
