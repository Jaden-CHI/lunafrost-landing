> **TL;DR** Google이 2026년 11월 19일 Genie 4를 Gemini API의 `v1beta Interactions API`로 개발자에게 공개했다. 고정 영상 클립이 아니라 실시간으로 조작 가능한 인터랙티브 세계를 스트리밍하는 완전히 새로운 카테고리의 API다. 유료 Gemini API 키가 필요하며, 과금은 프레임당 240 video tokens 기준으로 세계 1초당 약 $0.10, 세션 최대 120초다.

---

## Genie 4란 무엇인가, 그리고 기존 API와 무엇이 다른가

[Google 공식 블로그(2026-11-19)](https://blog.google/innovation-and-ai/technology/developers-tools/genie-4-in-gemini-api/)에 따르면, Genie 4는 텍스트 프롬프트·이미지·키보드 입력을 받아 실시간으로 반응하는 인터랙티브 세계를 생성하는 모델이다. Google은 이를 개발자가 직접 빌드할 수 있는 첫 번째 세계 모델(world model)로 소개하고 있다.

기존 Gemini API의 `generateContent` 엔드포인트나 Live API와는 완전히 별개의 경로를 사용한다. Genie 4는 `v1beta`의 **Interactions API** 에 배치되며, 애플리케이션이 서버에서 interaction을 생성한 뒤 브라우저에서는 WebRTC로, Python·Node.js 환경에서는 WebSocket으로 스트림에 연결하는 구조다.

출력 사양은 1280×720 해상도, 24fps, 48kHz 스테레오 오디오다.

---

## 세션 수명 주기: 4단계 워크플로

Interactions API의 핵심은 세션 수명 주기를 명시적으로 관리해야 한다는 점이다. [Google 공식 블로그](https://blog.google/innovation-and-ai/technology/developers-tools/genie-4-in-gemini-api/)가 설명하는 흐름은 다음 네 단계다.

1. **Interaction 생성** — 서버에서 `models/genie-4`로 interaction을 생성한다.
2. **스트림 연결** — 브라우저 클라이언트는 WebRTC로, 서버 사이드 클라이언트는 WebSocket으로 라이브 세션에 연결한다.
3. **세계 조종** — `world_setup` 이벤트를 전송한 뒤, 이동 이벤트 또는 텍스트 입력으로 세계를 실시간으로 조종한다.
4. **세션 종료** — 오류·취소·정상 종료 시 반드시 `complete()`를 호출해 생성과 과금을 중지한다.

`complete()` 호출을 빠뜨리면 세션 타임아웃까지 과금이 계속 발생할 수 있으므로, 클라이언트 코드에서 예외 처리와 함께 반드시 명시해야 한다.

브라우저 애플리케이션의 경우, 단일 interaction에 한정된 **임시 토큰**을 사용해 장기 API 키를 백엔드에만 보관하는 방식을 Google은 권장하고 있다.

## 구체적 예제: WebSocket으로 세계 초기화하기

아래는 Google 문서가 설명하는 흐름을 Python 의사 코드로 표현한 예시다. 실제 SDK 메서드명은 공식 문서에서 확인해야 한다.

```python
# 1. 서버에서 interaction 생성
interaction = client.models.create_interaction(model="models/genie-4")
session_token = interaction.token

# 2. WebSocket으로 스트림 연결
async with websocket.connect(interaction.stream_url) as ws:
    # 3. world_setup 이벤트 전송 (시드 이미지 포함, JPEG 48KB 이하 권장)
    await ws.send(json.dumps({
        "type": "world_setup",
        "prompt": "A sunlit forest path with fog",
        "seed_image_b64": compressed_jpeg_b64  # 48KB 이하
    }))

    async for frame in ws:
        process_frame(frame)  # 24fps 영상 프레임 처리

# 4. 반드시 complete() 호출
interaction.complete()
```

WebRTC 제어 채널에는 **64KB 페이로드 제한**이 있으며, Google 문서는 압축 JPEG 시드를 48KB 이하로 유지해 인코딩된 설정 이벤트가 제한 안에 들어오도록 권장하고 있다.

## 과금 구조

[Google 공식 블로그](https://blog.google/innovation-and-ai/technology/developers-tools/genie-4-in-gemini-api/)가 명시한 과금 구조는 다음과 같다.

| 항목 | 수치 |
|---|---|
| 과금 단위 | 프레임당 240 video tokens |
| 1M video output tokens | $17.50 |
| 세계 1초 출력 비용 | 약 $0.10 |
| 1분 비용 | 약 $6.05 |
| 최대 세션 길이 | 120초 |
| 120초 세션 영상 출력 비용 | 약 $12.10 |

무료 티어 Gemini API 키로는 사용할 수 없으며, 유료 티어 키가 필요하다.

---

## 주요 제한 사항

Google 공식 문서가 명시하는 제한 사항은 다음과 같다.

- **현재 미지원 기능**: 세로형 9:16 출력, 가변 프레임레이트, 라이브 마이크·웹캠 입력, 함수 호출(function calling), Search grounding, 구조화 출력, 세션 재개
- **시각적 일관성**: 처음 45~90초 구간이 가장 안정적이며, 60~90초 이후 시각적 안정성이 저하될 수 있다고 Google 문서는 경고한다
- **오브젝트 영속성**: 오브젝트를 8초 이상 시야 밖으로 옮기면 장면이 바뀔 수 있다
- **입력 지연**: 키보드 조작 약 0.5초, 텍스트 프롬프트 변경 1~2초
- **서빙 지역**: 미국, 서유럽, 일본 (한국 지역 지연 수준은 공식 문서에서 확인되지 않음)

## 활용 사례

[Google 공식 블로그](https://blog.google/innovation-and-ai/technology/developers-tools/genie-4-in-gemini-api/)가 언급하는 적합한 활용 사례는 세 가지다.

- **게임 프로토타이핑**: 플레이어 조작에 반응하는 세계를 빠르게 생성해 게임플레이 아이디어를 검증
- **영상 사전 시각화(film previs)**: 카메라 이동과 장면 구성을 실시간으로 탐색
- **에이전트·로보틱스 시나리오**: 에이전트가 조종 가능한 가상 환경을 동적으로 생성

## 접근 방법

Genie 4 Interactions API는 Gemini API와 Google AI Studio 두 경로로 접근할 수 있다. 모델 ID는 `models/genie-4`다.

11월 18일에는 Google AI Ultra 적격 구독자가 Project Genie를 통해 먼저 접근했으며, 11월 19일 발표는 유료 Gemini API 키를 보유한 개발자를 위한 추가 조치다. 구독자 릴리스가 브라우저 기반 생성·커뮤니티 갤러리를 강조한 반면, API는 세션 문서·유료 과금·사용 할당량을 추가한다.

---

## 주의 사항

- 과금 세부 수치($17.50/1M tokens, ~$0.10/sec)는 복수의 2차 자료가 같은 값을 인용하고 있으나, 본 리서치는 `ai.google.dev` 가격 페이지를 직접 열람하지 않았다. 프로덕션 적용 전 [Google 공식 블로그](https://blog.google/innovation-and-ai/technology/developers-tools/genie-4-in-gemini-api/) 및 Gemini API 공식 문서에서 최신 가격을 반드시 확인하라.
- Tier별 동시 세션·일일 요청 수치는 공식 rate-limits 페이지에서 직접 확인되지 않아 본 글에서 생략했다.
