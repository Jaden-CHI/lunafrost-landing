> **TL;DR** `alibaba/open-code-review`는 Alibaba가 2년간 내부 AI 코드 리뷰 도구로 운영하며 수백만 건의 결함을 탐지한 뒤 2026년 5월 Apache-2.0으로 오픈소스 공개한 CLI입니다. 결정론적 파이프라인과 LLM 에이전트를 조합한 하이브리드 설계가 핵심이며, Claude Code·GitHub Copilot·OpenCode 등 주요 에이전트에 플러그인으로 붙일 수 있습니다.

---

## 왜 또 다른 AI 코드 리뷰 도구인가

PR마다 LLM을 통째로 붙이는 접근은 흔합니다. 그러나 토큰 비용이 많이 들고, 줄 번호가 엉키거나 맥락을 놓치는 오탐이 잦다는 불만도 그만큼 많습니다. `open-code-review`가 다른 점은 **"무엇을 LLM에 맡기고 무엇을 맡기지 않을지"** 를 명확히 나눈 하이브리드 아키텍처에 있습니다.

[GitHub README](https://github.com/alibaba/open-code-review/blob/main/README.md)에 따르면, Alibaba 그룹은 이 도구를 **수만 명의 내부 개발자에게 제공하며 수백만 개의 코드 결함을 발견**한 뒤 오픈소스로 공개했습니다. 현업에서 2년을 버틴 도구라는 점이 초기 설계 결정의 근거가 됩니다.

---

## 하이브리드 아키텍처: 결정론 + LLM

[공식 사이트](https://alibaba.github.io/open-code-review/)와 README가 설명하는 설계 원칙은 두 레이어로 나뉩니다.

| 레이어 | 역할 | 예시 |
|---|---|---|
| **결정론적 엔지니어링** | 확실성 처리 | 작업 분할, 파일 필터링, 줄 번호 위치 지정, 규칙 라우팅, 비동기 스케줄링 |
| **LLM 에이전트** | 의미론 처리 | 위험 감지, 컨텍스트 탐색, 이슈 분류 |

이 분리 덕분에 LLM은 "어느 줄인가"를 고민하지 않고 "이 패턴이 왜 위험한가"에만 집중합니다. 결과는 **줄 단위(line-level) 코멘트**로 출력되며, NPE·스레드 안전성·XSS·SQL 인젝션 같은 내장 규칙셋이 사전 필터링을 담당합니다.

지원 언어는 Java, TypeScript, Go, Python, Kotlin, Rust, C/C++, Swift, Solidity, Verilog 등 **40개 이상**입니다. OpenAI 및 Anthropic API와 호환됩니다.

## 설치와 기본 사용법

[공식 사이트](https://alibaba.github.io/open-code-review/) 기준 설치는 npm 한 줄입니다.

```bash
npm i -g @alibaba-group/open-code-review
```

설치 후 LLM 프로바이더와 모델을 설정합니다.

```bash
ocr config provider   # 빌트인 프로바이더 선택 또는 커스텀 추가
ocr config model      # 모델 지정 (연결성 테스트 자동 수행)
```

이후 세 가지 기본 리뷰 패턴을 사용할 수 있습니다.

```bash
# 현재 워크스페이스 변경사항 리뷰
ocr review

# 브랜치 간 diff 리뷰
ocr review --from main --to feature-auth

# 특정 커밋 리뷰
ocr review --commit abc123
```

git 히스토리 없이도 전체 파일 스캔이 가능하며, `--json` 플래그로 구조화된 JSON 출력을 받을 수 있어 AI 호스트 에이전트와 연동하기 좋습니다.

## AI 에이전트 플러그인 연동

CLI 단독 사용 외에도 주요 AI 에이전트에 플러그인으로 등록할 수 있습니다. [플러그인 README](https://github.com/alibaba/open-code-review/blob/main/plugins/open-code-review/README.md) 기준입니다.

**Claude Code**
```
/plugin marketplace add alibaba/open-code-review
```
설치 후 `/open-code-review:review`와 `/open-code-review:delegate-review` 슬래시 커맨드가 추가됩니다.

**GitHub Copilot CLI**
```
copilot plugin install alibaba/open-code-review:plugins/open-code-review
```

**Kimi Code**
```
/plugins install https://github.com/alibaba/open-code-review
```
`/open-code-review:review` 및 `/open-code-review:delegate-review` 커맨드와 로컬 ocr CLI 기반 리뷰 스킬을 제공합니다.

**OpenCode**  
[OpenCode 플러그인 README](https://github.com/alibaba/open-code-review/blob/main/plugins/open-code-review/opencode/README.md)에 따르면, `ocr_review` 도구가 네이티브 도구로 등록되며 `/ocr-review`, `/ocr-health` 슬래시 커맨드를 지원합니다. 워크스페이스 변경사항, 단일 커밋, ref 범위 리뷰 후 구조화된 JSON 결과를 반환합니다.

**Delegation 모드**: AI 코딩 에이전트가 직접 리뷰를 수행하는 모드로, 이때 발생하는 LLM 토큰 비용은 사용자가 선택한 프로바이더 요금표를 따릅니다(`open-code-review` 자체는 무료).

## CI/CD 연동

GitHub Actions 및 GitLab CI와의 공식 연동을 지원합니다. PR 생성 시 자동으로 `ocr review`를 실행하고 줄 단위 코멘트를 PR 리뷰로 게시하는 파이프라인을 구성할 수 있습니다.

## 정리

`open-code-review`는 "LLM이 모든 걸 알아서 한다"는 단순 접근 대신, 결정론적 파이프라인이 정확도와 비용을 잡고 LLM이 의미 판단만 담당하는 구조로 설계되었습니다. 2년간의 내부 운영 이력과 40개 이상의 언어 지원, 주요 AI 에이전트 플러그인 생태계가 갖춰진 점은 실무 도입을 고민하는 개발자에게 충분한 출발점이 될 것입니다.
