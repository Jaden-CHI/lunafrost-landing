## TL;DR

- **MiniMax H3**는 2026-08-03 공개된 오픈 웨이트 영상 생성 모델로, 비디오와 스테레오 오디오를 **한 번의 추론**으로 동시 출력한다.
- 최대 사양은 2K 해상도·15초·24FPS·32kHz 스테레오이며, 텍스트·첫/마지막 키프레임·참조 이미지/영상/오디오를 혼합 입력할 수 있다.
- **FreeVideo**는 MiniMax H3를 VRAM 8GB·RAM 16GB 소비자 GPU에서 실행하는 Apache 2.0 오픈소스 추론 엔진이다.
- 라이선스는 **MiniMax H3 Community License**로 영토·허용 사용 제한이 존재하므로 상업 목적이라면 원문 확인이 필수다.

---

## 왜 MiniMax H3인가

지금까지 로컬 AI 영상 생성 도구들은 오디오를 별도 단계에서 붙이거나 아예 다루지 않았다. MiniMax H3는 이 흐름을 바꾼다. [공식 GitHub README](https://github.com/MiniMax-AI/MiniMax-H3)에 따르면 H3는 "텍스트·이미지·영상·오디오로 구성된 멀티모달 컨텍스트를 통합 이해하고, 네이티브 스테레오 오디오와 함께 비디오를 생성할 수 있는 범용 옴니모달 생성 시스템"이다.

동일 Omni-Transformer가 영상 VAE와 오디오 VAE를 공동 예측하는 구조이므로, 후처리로 오디오를 합성하는 파이프라인과는 아키텍처 수준에서 다르다. Wan 2.2가 오디오를 다루지 않고, LTX-2.5가 오디오를 별도로 처리하는 것과 대비되는 차별점이다.

---

## 출력 사양과 생성 모드

[MiniMax 공식 뉴스(2026-08-03)](https://www.minimax.io/news/minimax-h3-open-source)와 [GitHub MiniMax-AI/MiniMax-H3](https://github.com/MiniMax-AI/MiniMax-H3)에서 확인된 사양은 다음과 같다.

| 항목 | 사양 |
|---|---|
| 최대 해상도 | 2K |
| 최대 길이 | 15초 |
| 프레임레이트 | 24 FPS |
| 오디오 | 스테레오 32kHz |
| 기본 출력 길이 | 4–15초 |
| H3-Base 해상도 | 768p |

생성 모드는 세 가지로 정리된다([vllm-omni 레시피](https://github.com/vllm-project/vllm-omni/blob/main/recipes/MiniMaxAI/MiniMax-H3.md) 기준).

- **T2VA** — 텍스트 프롬프트만으로 영상+오디오 생성
- **FL2VA** — 첫 프레임(First)·마지막 프레임(Last) 키프레임을 지정해 그 사이를 채우는 방식
- **Ref2VA** — 이미지·영상·오디오 참조를 혼합 입력해 스타일·내용을 제어

예를 들어 FL2VA를 쓰면 "문이 닫혀 있는 첫 프레임"과 "문이 열린 마지막 프레임"만 준비한 뒤 중간 동작과 그에 맞는 삐걱 소리까지 한 번에 뽑아낼 수 있다. 텍스트-투-비디오인 T2VA는 이미지 입력 없이 프롬프트만으로 동작한다.

## FreeVideo로 소비자 GPU에서 실행하기

MiniMax H3 모델 가중치를 직접 돌리려면 상당한 VRAM이 필요하다. [FreeVideo(FlashML-org/FreeVideo)](https://github.com/FlashML-org/FreeVideo)는 Video DeltaNet(VDN) 기반의 하이브리드 어텐션 모델 VDN-H3를 활용해 이 요건을 대폭 낮춘다.

**FreeVideo 최소 하드웨어 요건** (공식 README 기준):
- VRAM: 8GB
- RAM: 16GB

FreeVideo는 하드웨어에 맞춰 가속 경로를 자동으로 선택한다. 별도로 환경을 튜닝하지 않아도 GPU 사양에 따라 최적 경로가 적용된다.

**주요 릴리스 이력** (GitHub 릴리스 노트 기준):

| 버전 | 날짜 | 주요 변경 |
|---|---|---|
| v0.2.0 | 2026-10-05 | 품질 단계 4개 추가 (Light / Medium / High / Max) |
| v0.1.2 | 2026-10-05 | Apple Silicon Mac 로컬 생성 프리뷰 지원 |

품질 단계를 선택할 수 있다는 것은 VRAM이 넉넉하지 않은 환경에서 Light로 빠른 프로토타입을 만들고, 렌더링 최종본은 Max로 뽑는 워크플로를 구성할 수 있다는 의미다.

FreeVideo의 코드 라이선스는 **Apache License 2.0**이다. 단, FreeVideo가 실행하는 MiniMax H3 모델 가중치는 별도의 **MiniMax H3 Community License**를 따르며, 이 라이선스에는 영토 및 허용 사용 제한이 포함돼 있다. 상업적 용도로 사용하기 전에 [MiniMax 공식 뉴스](https://www.minimax.io/news/minimax-h3-open-source) 및 GitHub 저장소의 라이선스 원문을 반드시 직접 확인해야 한다.

## 15초 한계를 넘으려면: H3-LongVideos

MiniMax H3의 단일 추론 최대 길이는 15초다. [H3-LongVideos(GitHub: Smite79/MiniMax-H3-LongVideos)](https://github.com/Smite79/MiniMax-H3-LongVideos)는 ComfyUI 노드로, 이 한계를 극복하기 위해 장면을 샷 단위로 나눠 렌더링한 뒤 하나의 사운드트랙으로 이어 붙이는 접근을 취한다. 공식 MiniMax 릴리스가 아닌 커뮤니티 프로젝트이므로, 품질과 안정성은 본인이 직접 검증해야 한다.

---

## 실사용 전 확인해야 할 것들

다음 항목들은 현재 공식 문서에서 확인되지 않았거나 불확실한 사항이다.

1. **라이선스 세부 조항**: MiniMax H3 Community License의 영토·허용 사용 제한 전문은 본 글에서 열람하지 않았다. 상업적 사용 전 원문 확인이 필수다.
2. **FreeVideo의 실험적 성격**: FreeVideo가 사용하는 VDN-H3는 MiniMax가 아닌 OpenVDN([GitHub: OpenVDN/vdn-minimax-h3](https://github.com/OpenVDN/vdn-minimax-h3)) 기반의 독립 연구 모델이다. MiniMax 공식 추론 경로와 성능 차이가 있을 수 있다.
3. **한국어 UI**: FreeVideo의 한국어 인터페이스 지원 여부는 공식 문서에서 확인되지 않는다.
4. **실제 생성 품질**: 본 글은 공식 README와 릴리스 노트만을 근거로 작성했으며, 직접 로컬 실행을 재현한 경험을 포함하지 않는다.

## 정리

MiniMax H3는 오디오와 비디오를 단일 패스로 생성한다는 점에서 기존 로컬 영상 생성 도구와 아키텍처 수준의 차이를 갖는다. FreeVideo는 이 모델을 소비자 GPU(VRAM 8GB)에서 실행할 수 있도록 하는 현재 가장 접근하기 쉬운 오픈소스 경로다. 단, 모델 가중치 라이선스 조항을 반드시 직접 읽어본 후 프로젝트에 적용 여부를 판단하길 권한다.
