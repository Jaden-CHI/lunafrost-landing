> **TL;DR** — [CLI-Anything](https://github.com/HKUDS/CLI-Anything)은 Blender·LibreOffice·GIMP 같은 데스크탑 앱을 AI 에이전트가 직접 호출할 수 있는 터미널 명령어로 자동 변환하는 오픈소스 도구입니다. 스크린샷·클릭 없이 구조화된 JSON 출력으로 에이전트가 소프트웨어를 제어할 수 있으며, Apache 2.0으로 무료입니다.

---

## 왜 GUI 자동화가 AI 에이전트에게 문제인가

AI 에이전트가 소프트웨어를 다루는 현재 방식은 크게 두 가지입니다. 화면을 캡처해 좌표를 클릭하는 방식(PyAutoGUI, RPA 계열)과, 브라우저를 조작하는 방식(Playwright, browser-use 계열)입니다. 두 방법 모두 데스크탑 GUI 앱에서는 한계가 뚜렷합니다. UI 레이아웃이 조금만 바뀌어도 스크립트가 깨지고, 에이전트가 앱의 실제 기능 구조를 이해하지 못한 채 "보이는 것"에만 의존하기 때문입니다.

홍콩대학교 데이터인텔리전스 연구소(HKUDS — LightRAG를 만든 팀)가 개발한 [CLI-Anything](https://github.com/HKUDS/CLI-Anything)은 이 문제를 다른 방향으로 접근합니다. GUI를 없애는 대신, GUI 앱의 기능을 AI가 직접 호출 가능한 CLI 인터페이스로 변환합니다.

---

## 핵심 개념: 7단계 하네스 생성 파이프라인

CLI-Anything의 플러그인(v1.0.0)은 `cli-anything`, `refine`, `test`, `validate` 네 가지 명령어를 통해 [완전한 7단계 파이프라인](https://github.com/HKUDS/CLI-Anything/blob/main/cli-anything-plugin/README.md)을 구현합니다. 대상 소프트웨어 경로를 지정하면, 파이프라인이 해당 앱의 기능을 분석하고 에이전트가 소비할 수 있는 CLI 하네스를 자동으로 생성합니다.

생성된 CLI의 특징은 세 가지입니다.

- **REPL 모드 기본 제공**: 대화형 세션으로 여러 명령을 연속 실행 가능
- **`--json` 플래그**: 에이전트가 파싱하기 쉬운 머신 리더블 출력 반환
- **전역 세션 상태와 undo/redo**: 작업 흐름을 상태로 관리

## CLI-Hub: 사전 제작된 CLI 레지스트리

직접 CLI를 생성하지 않아도 됩니다. 2026년 3월 17일 출시된 [CLI-Hub](https://hkuds.github.io/CLI-Anything/)는 단일 `pip` 명령으로 설치 가능한 중앙 레지스트리입니다. 공식 README 기준으로 Blender, Inkscape, Audacity, OBS Studio, LibreOffice, Kdenlive, Shotcut, draw.io, Zoom, Ollama, ComfyUI, FreeCAD, QGIS, Obsidian, Zotero 등의 CLI가 포함되어 있습니다.

```bash
pip install cli-anything-hub
cli-hub list           # 등록된 CLI 목록 확인
cli-hub search blender # 검색
cli-hub install blender-cli # 설치
```

CLI-Hub v0.2.0은 pip, npm, brew, 번들/시스템 도구 등 다양한 설치 소스를 지원하며, `public_registry.json`으로 레지스트리를 관리합니다.

## SKILL.md: 에이전트 자동 발견 메커니즘

2026년 3월 16일 추가된 SKILL.md 생성 기능(Phase 6.5)은 CLI-Anything의 차별점 중 하나입니다. 생성된 모든 CLI 패키지 내부에 AI가 검색 가능한 스킬 정의 파일이 함께 포함됩니다. `pip install` 후 호환 에이전트(ReplSkin 기반)가 자동으로 이 파일을 감지해 사용 가능한 도구로 등록합니다.

2026년 3월 23일에는 CLI-Hub 메타 스킬이 추가되어, 에이전트가 스스로 CLI-Hub를 검색하고 필요한 CLI를 자율적으로 설치하는 흐름이 가능해졌습니다.

에이전트에 메타 스킬을 등록하는 명령은 다음과 같습니다.

```bash
npx skills add hkuds/cli-anything --skill cli-hub-meta-skill -g -y
# -g: 전역 설치, -y: 확인 프롬프트 생략
```

## 구체적 예제: LibreOffice를 에이전트로 제어하기

[공식 README](https://raw.githubusercontent.com/HKUDS/CLI-Anything/main/README.md)에 명시된 `cli-anything-libreoffice` 사용 예입니다.

```bash
# 새 Writer 문서 생성
cli-anything-libreoffice document new -o report.json --type writer

# 제목 추가
cli-anything-libreoffice --project report.json writer add-heading \
  -t "Q1 Report" --level 1

# 에이전트가 소비할 수 있는 JSON 출력으로 문서 정보 조회
cli-anything-libreoffice --json document info --project report.json

# PDF로 내보내기
cli-anything-libreoffice --project report.json export render output.pdf \
  -p pdf --overwrite
```

에이전트 입장에서는 LibreOffice의 GUI를 열거나 화면을 캡처할 필요 없이, 위 명령어를 순서대로 실행하는 것만으로 문서 생성·편집·내보내기가 완결됩니다.

## Claude Code로 새 CLI 생성하기

Claude Code 플러그인을 통해 로컬에 설치된 소프트웨어의 CLI를 직접 생성할 수 있습니다.

```
/plugin marketplace add HKUDS/cli-anything
/plugin install cli-anything
```

설치 후 `/cli-anything ./gimp`처럼 소프트웨어 경로를 지정하면 7단계 파이프라인이 자동으로 CLI를 생성합니다. Cursor 플러그인도 별도 설치 스크립트로 지원하며, Windows/macOS/Linux 각각 경로가 다릅니다.

**준비물 요약**

| 항목 | 요건 |
|---|---|
| Python | 3.10 이상 |
| AI 에이전트 | Claude Code, Cursor, Codex, OpenClaw 등 SKILL 호환 에이전트 중 택 1 |
| Windows 추가 | Git for Windows 또는 WSL (Bash 셸 필요) |
| 대상 소프트웨어 | 로컬에 설치되어 있어야 함 |

## 대안 비교

| 방법 | 특징 | 한계 |
|---|---|---|
| Playwright/Puppeteer MCP | 브라우저 기반 웹 앱 자동화 | 데스크탑 GUI 앱 미지원 |
| browser-use | AI 에이전트 브라우저 직접 조작 | 브라우저 한정 |
| PyAutoGUI | 화면 캡처+좌표 클릭 | UI 변경에 취약, 느림 |
| xdotool (Linux) | X11 환경 GUI 자동화 | Linux 전용, 비구조적 출력 |

CLI-Anything은 데스크탑 앱에 특화되어 있으며, 구조화된 JSON 출력으로 에이전트 통합이 용이하다는 점에서 위 도구들과 보완 관계에 있습니다.

## 제약 및 주의사항

몇 가지 제약은 미리 인지하는 것이 좋습니다.

- **대상 소프트웨어 필수**: Blender, GIMP 등이 로컬에 설치되어 있지 않으면 CLI 생성 자체가 불가합니다.
- **공급망 위험**: CLI-Hub가 pip, npm, brew 소스의 서드파티 패키지를 설치하므로, 프로덕션 환경에서는 별도 보안 검토가 필요합니다.
- **플랫폼별 문서 한계**: Cursor 플러그인의 플랫폼별 상세 오류 처리 문서는 공식 README 외에 아직 제한적입니다.
- **프로덕션 안정성**: 직접 실행한 검증이 없으므로 실제 환경에서의 안정성은 별도 테스트가 필요합니다.
