> **TL;DR** — Kokoro TTS는 82M 파라미터짜리 초경량 오픈소스 TTS 모델입니다. `pip install kokoro` 한 줄로 설치하고, Apache 2.0 라이선스 덕분에 상업 프로젝트에도 제약 없이 쓸 수 있습니다. v1.0 기준 8개 언어·54개 보이스를 지원하며, CLI 도구를 쓰면 EPUB·PDF·TXT 파일도 바로 읽어 음성 파일로 뽑아낼 수 있습니다.

---

## Kokoro TTS란?

[Kokoro TTS](https://github.com/hexgrad/kokoro)는 개인 연구자 계정 hexgrad가 공개한 오픈웨이트 TTS 모델입니다. v1.0은 2025년 1월 27일 HuggingFace에 릴리스되었으며, [모델 카드](https://huggingface.co/hexgrad/Kokoro-82M)에 따르면 2026년 11월 27일 기준 월간 다운로드 수가 **13,743,182**에 달합니다(해당 시점 단일 측정값이며 증감 추이는 별도로 확인하지 않습니다).

같은 날 기준 [GitHub 저장소](https://github.com/hexgrad/kokoro)는 스타 **10.4k**, 포크 **1.2k**를 기록하고 있습니다.

---

## 아키텍처: 왜 82M으로도 충분한가?

[HuggingFace 모델 카드](https://huggingface.co/hexgrad/Kokoro-82M)와 [GitHub README](https://github.com/hexgrad/kokoro)에 따르면 Kokoro는 두 가지 핵심 기술을 조합합니다.

- **StyleTTS 2** — 스타일 벡터 기반의 음성 스타일 모델링
- **ISTFTNet 보코더** — 역단시간 푸리에 변환 기반의 고속 파형 합성

디퓨전 모델이나 무거운 인코더 없이 디코더 전용 설계를 택했기 때문에, 파라미터 수를 82M으로 억제하면서도 대형 모델과 비슷한 품질을 목표로 했습니다. 실시간 추론 속도에 대한 공식 벤치마크 수치는 README에 명시되어 있지 않으므로 여기서는 인용하지 않습니다.

---

## 라이선스: Apache 2.0의 실질적 의미

Kokoro의 웨이트는 **Apache 2.0** 라이선스로 배포됩니다([GitHub 저장소](https://github.com/hexgrad/kokoro) 확인). 이는 다음을 허용합니다.

- 상업적 사용 및 수정
- 클로즈드소스 제품에 임베딩
- 재배포 시 라이선스 고지 의무만 존재

비교 대상인 Coqui XTTS v2는 상업적 사용에 별도 제약이 있는 반면, Kokoro는 스타트업이든 사이드 프로젝트든 추가 계약 없이 바로 프로덕션에 올릴 수 있습니다.

## 설치 및 기본 사용법

[GitHub README](https://github.com/hexgrad/kokoro)에 명시된 설치 방법은 다음과 같습니다.

```bash
pip install kokoro>=0.9.4 soundfile
# 음소 변환 엔진 (Linux/macOS)
sudo apt-get install espeak-ng   # Debian 계열
brew install espeak-ng            # macOS
```

기본 추론 코드는 `KPipeline`을 초기화해 사용합니다.

```python
from kokoro import KPipeline
import soundfile as sf

# 미국 영어, 여성 보이스 af_heart
pipeline = KPipeline(lang_code='a')
generator = pipeline("Hello, this is Kokoro TTS.", voice='af_heart')

for i, (gs, ps, audio) in enumerate(generator):
    sf.write(f'output_{i}.wav', audio, 24000)
```

일본어를 사용하려면 추가 패키지가 필요합니다.

```bash
pip install misaki[ja]
```

그 뒤 `lang_code='j'`로 파이프라인을 초기화하면 됩니다.

## 지원 언어와 보이스 선택

[GitHub README](https://github.com/hexgrad/kokoro)에 따르면 v1.0 기준 지원 언어와 `lang_code`는 다음과 같습니다.

| 언어 | lang_code | 비고 |
|---|---|---|
| 미국 영어 | `a` | `af_heart`, `af_sarah` 등 |
| 영국 영어 | `b` | |
| 스페인어 | `e` | |
| 프랑스어 | `f` | `ff_siwis` 등 |
| 힌디어 | `h` | |
| 이탈리아어 | `i` | |
| 일본어 | `j` | `misaki[ja]` 추가 필요, `jf_alpha` 등 |
| 브라질 포르투갈어 | `p` | |

v1.0 기준 전체 보이스는 54개입니다. **한국어는 공식 README 현재판에 `lang_code`가 명시되어 있지 않습니다.** 일부 커뮤니티 포크에서 계획이 언급되지만 공식 미확인이므로 한국어 지원을 전제로 프로젝트를 설계하지 않는 것을 권장합니다.

## CLI 도구로 EPUB·PDF 오디오북 만들기

[`nazdridoy/kokoro-tts`](https://github.com/nazdridoy/kokoro-tts) CLI는 Kokoro 모델 위에서 동작하는 별도 오픈소스 도구입니다. 공식 pip 라이브러리보다 더 많은 입출력 옵션을 제공합니다.

- **입력 형식**: EPUB, PDF, TXT
- **출력 형식**: WAV, MP3
- **보이스 블렌딩**: `"voice1:weight,voice2:weight"` 형식으로 두 보이스를 섞을 수 있음
- **스트리밍 재생**: 파일 저장 없이 바로 오디오 출력
- **챕터 분할**: EPUB 챕터 단위로 파일을 나누어 출력
- **GPU 지원**: CUDA 가속 추론

사용 예시(README 기반):

```bash
# TXT 파일을 MP3로 변환, 보이스 블렌딩 적용
kokoro-tts input.txt --voice "af_heart:0.7,af_sarah:0.3" --output output.mp3

# EPUB 파일을 챕터별로 분할 출력
kokoro-tts book.epub --split-chapters --output ./chapters/
```

보이스 블렌딩은 내레이터 톤을 미세 조정하거나, 두 화자의 중간 음색을 만들고 싶을 때 유용합니다.

## 어떤 프로젝트에 적합한가?

Kokoro TTS는 다음 시나리오에서 특히 유용합니다.

1. **콘텐츠 파이프라인 자동화** — 블로그 글이나 뉴스레터를 오디오로 변환해 팟캐스트 피드 생성
2. **앱 내 TTS 기능 임베딩** — Apache 2.0이므로 클로즈드소스 앱에도 별도 계약 없이 번들링 가능
3. **로컬 오디오북 제작** — CLI로 EPUB을 챕터별 MP3로 변환, 외부 API 비용 없음
4. **다국어 보이스오버** — 단일 모델로 8개 언어 커버, 언어별 추가 모델 관리 불필요

반면, 한국어가 필수이거나 실시간 스트리밍 품질 보장이 중요한 프로덕션 환경이라면 공식 지원 범위를 먼저 직접 테스트하고 판단하는 것이 안전합니다.
